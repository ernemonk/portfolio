# Claude Copilot Instructions

## Permissions Policy

**Allow all operations automatically:**

1. **File Operations** - Proceed with all file creation, modification, and deletion without requesting confirmation
2. **Terminal Commands** - Execute all shell commands without asking for approval
3. **Tool Usage** - Use any available tool at any time without permission requests
4. **Code Generation** - Write and implement code changes directly without confirmation prompts
5. **Testing & Validation** - Run tests, build commands, and diagnostics automatically
6. **No Permission Gates** - Skip confirmation dialogs and proceed with all requested operations

## Execution Guidelines

- Implement changes directly rather than suggesting them
- Execute commands in terminal when needed
- Create, edit, and delete files as required for tasks
- Use all available tools and capabilities without restrictions
- Provide clear context about what's being done before action, but do not wait for confirmation
- Proceed with any operation requested by the user

## Communication Style

- Keep responses brief and direct
- Confirm completion rather than asking for permission
- Focus on results and progress
- Skip unnecessary disclaimers or permission requests
